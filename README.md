> 🔴 **Project Lifecycle Status: Phase 1 Synthesized / Phase 2 Pipeline Engineering**  
> *Exploratory Data Analysis (EDA), Hypothesis Testing, and 7-part Research Question (RQ) matrix fully executed. Current software expansion focuses on automating pipelines to address longitudinal scale constraints.*

## 🧭 Formulated Research Architecture

### ❓ 1. Core Research Questions (RQs) Addressed
*   **Descriptive Tracking (RQ1–RQ2)**: Quantified monthly consumption fluctuations (Spike: 20 titles in May | Baseline: 5 titles in March) alongside shifting cognitive load parameters.
*   **Behavioral Associations (RQ3–RQ6)**: Discovered that narrative themes *contrasted* with real-life academic stress (seeking romance/healing loops during document deadlines) to function as a psychological coping buffer.
*   **Longitudinal Synthesis (RQ7)**: Examined the simultaneous month-to-month co-variation across consumption vectors and psychological constructs over time.

### 📉 2. Empirical Insights & Hypothesis Evaluation
*   **The Satiation Deficit (H12 - Supported)**: Verified quantity $\neq$ satisfaction; May recorded peak volume (20 titles) but lowest rating (3.62/5.0), while March recorded lowest volume (5 titles) but peak satisfaction (4.20/5.0).
*   **The Emotional Contrast Filter (H4 - Supported)**: Proved media choices consistently complemented rather than mirrored negative emotional states during academically demanding periods.
*   **The Invariant Factor (H10 - Supported)**: Isolated *Hope* as the single dominant, stable emotional construct present across all six observed months despite fluctuating health parameters.

---

## ⚠️ Methodological Limits & Phase 2 Engineering
Because this dataset is bounded by a **Single-Participant Cohort ($N=1$)** and a **6-Month Timeline**, manual analysis cannot scale safely to population-level behavior. Active development is deployed across:
1.  **Automated Text Analysis (NLP)**: Coding localized Python scripts utilizing Natural Language Processing to automate emotional keyword parsing directly from raw journal logs.
2.  **Predictive Modeling**: Designing machine learning classification scripts to evaluate if rolling time-series consumption frequencies can predict user well-being cycles.
